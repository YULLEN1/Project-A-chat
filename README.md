## 💬 Проект «А-Чат»

**А-Чат** — приложение для онлайн-коммуникации с личными чатами, группами и каналами, обменом сообщениями, файлами и медиа, а также голосовыми и видеозвонками.

В рамках проекта я занималась ручным тестированием web- и адаптивной версии приложения. Провела декомпозицию функциональности и разработала mind map тестирования, на основе которой сформировала и поддерживала чек-лист из 600+ проверок.

Проводила функциональное, smoke- и regression-тестирование, тестирование новой функциональности и retest исправленных дефектов. При проектировании проверок применяла классы эквивалентности, анализ граничных значений, переходы состояний, позитивные и негативные сценарии, проверки ролей и прав доступа.

Также анализировала клиент-серверное взаимодействие с помощью Chrome DevTools и работала с REST API/JSON.
